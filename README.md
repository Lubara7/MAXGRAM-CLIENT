# TG-MAX Ultimate

Начальный каркас самостоятельного Android-клиента MAX с интерфейсом по мотивам Telegram/Nagram X.

**Состояние:** экраны и локальная архитектура авторизации готовы для разработки. Реальный вход в MAX ещё не подключён. Чаты, звонки, медиа и push-уведомления в этот этап не входят.

## Что реализовано

- Ввод телефона с выбором страны, проверкой через libphonenumber и нормализацией E.164.
- Ввод кода подтверждения, таймер повторной отправки, ошибки и защита от повторных нажатий.
- Восстановление сессии и выход; шифрование сессии AES-GCM ключом Android Keystore.
- Светлая и тёмная темы; выбор языка в приложении и системных настройках Android.
- Только `ru`, `en`, `es`, `uz` (латиница), `pt` (европейский), `pt-BR`, `fr`, `be`.
- Входа по QR-коду нет.

## Две отдельные сборки

| Вариант | Идентификатор | Поведение |
|---|---|---|
| `demoDebug` | `io.github.lubara7.tgmax.demo` | Видимая отметка «Демо». Сообщения не отправляются. Для корректного номера используйте код **12345**. |
| `productionDebug` | `io.github.lubara7.tgmax` | Адаптер Open Client API пока возвращает понятное сообщение о ненастроенном подключении. Демо-адаптер в эту сборку не входит. |

Демонстрационный код действителен 5 минут, повторная отправка доступна через 30 секунд. Это параметры демонстрации, а не заявленные параметры MAX. После 5 неверных попыток нужен новый код. После успешного входа показан экран-заготовка; списка чатов пока нет.

## Сборка

Нужны JDK 17 и Android SDK: `platforms;android-36`, `build-tools;35.0.0`, `platform-tools`. Укажите путь SDK через `ANDROID_HOME` или локальный `local.properties` (`sdk.dir=...`); этот файл не коммитится.

```bash
./gradlew :app:assembleDemoDebug :app:assembleProductionDebug
```

В Windows используйте `gradlew.bat`. В Android Studio выберите `demoDebug` в **Build Variants** и запустите модуль `app`. Минимальная версия устройства — Android 8.0 (API 26).

Зафиксированная базовая связка: AGP 8.13.2, Gradle 8.13, Kotlin 2.2.20, Compose BOM 2025.10.00. Версии находятся в `gradle/libs.versions.toml`, контрольная сумма Gradle — в настройках Wrapper.

## Проверки

```bash
./gradlew :core:domain:test \
  :core:data:testDemoDebugUnitTest :core:data:testProductionDebugUnitTest \
  :core:localization:testDebugUnitTest :feature:auth:testDebugUnitTest \
  :app:lintDemoDebug :app:lintProductionDebug \
  :core:data:assembleDemoDebugAndroidTest
```

Тесты проверяют ошибки и переходы авторизации, повторные запросы, отмену, срок действия кода, сохранение/удаление сессии и полноту локализаций. GitHub Actions запускает эти проверки и собирает оба debug APK.

Отдельно на подключённом устройстве или эмуляторе:

```bash
./gradlew :core:data:connectedDemoDebugAndroidTest
```

Эти инструментальные тесты проверяют реальный Android Keystore: шифрование, чтение, очистку и отклонение изменённого шифротекста. Компиляция тестового APK сама по себе не означает запуск этих тестов.

## Подключение настоящего MAX

Официальная программа [Open Client API](https://dev.max.ru/docs/open-api/) предназначена для альтернативных клиентов. [Информация о подключении](https://legal.max.ru/openclient-docs) описывает получение App-ID и полной документации. Bot API не используется для входа в личный аккаунт.

Реализуйте `OpenClientAuthGateway` по полученной документации. Значение App-ID можно передать локально через `-Pmax.appId=...`; само по себе оно не включает реальный вход. Секреты, сертификаты и сессии в репозиторий не добавляются. Собственный сервер-посредник не предусмотрен.

## Структура

| Модуль | Ответственность |
|---|---|
| `app` | Запуск, навигация, явная сборка зависимостей, выбор backend-варианта |
| `core/domain` | Независимые модели и контракты авторизации |
| `core/data` | Репозиторий, шлюз MAX на устройстве и защищённое хранилище |
| `core/ui` | Тема и общие компоненты |
| `core/localization` | Переводы, языки и их переключение |
| `feature/auth` | Экраны и ViewModel авторизации |

Подробнее: [архитектура](docs/architecture.md), [авторизация](docs/authentication.md), [локализация](docs/localization.md), [интеграция MAX](docs/max-integration.md).
