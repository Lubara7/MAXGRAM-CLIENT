Экспериментальная сборка MaxGram на базе NextAlone/Nagram с интерфейсом Telegram и транспортом MAX.

**Android 8.1+ · ARM64 · тестовый Pre-release.** Клиент ещё не соответствует всем критериям готовности ТЗ v2.

Изменения:
- Исправлен сбой первого запуска при загрузке нативного движка.
- Проверены экран входа RU/EN, список 44 стран, помощь и документы MAX.
- Добавлены серверные статусы MAX, скрытие точного статуса заблокированных контактов и исправление перехода из шапки в профиль.
- Добавлено отладочное меню по семи нажатиям на версию: журнал метаданных без токенов, номеров и текста сообщений.
- Исправлены повторная загрузка чатов, миграция базы и локальное хранение полученных удалённых сообщений по выбору пользователя.
- Профиль нового входа обновлён до WEB 26.11.8; сохранённые сеансы и выбранные вручную профили сохраняются.

Проверки: 71 тест протокола, проверки Android и установка именно этого APK в эмуляторе прошли. Проверки локальных функций используют синтетические данные.

**Ограничения:** реальный вход и 72 часа наблюдения аккаунта ещё не проверены. Медиа, подтверждение QR в «Устройствах», звонки и часть очистки неподдерживаемых меню не завершены. Отсутствие блокировки аккаунта не гарантируется.

APK опубликован без пересборки: исходный коммит `58931cf69beffba50a434116aa5c03177a56ee27`. Контрольные суммы, сведения о подписи, результаты автоматических проверок и соответствующий архив исходников приложены.
