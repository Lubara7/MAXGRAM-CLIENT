# MAXGRAM CLIENT 0.4.0-dev.4 — Telegram Android design

Экспериментальная Android-сборка на основе Komet. Интерфейс переработан по исходникам официального Telegram Android, commit `21f7d109da6ab3506c9e9577f98c6a38771ab335`.

- Настройки: оригинальные иконки Telegram `msg2_*`, строки 50 dp, отступ заголовка 71 dp, плоские секции и светлая верхняя панель. Поиск открывает работающие пункты настроек.
- Переключатели, радиокнопки и ползунки перерисованы с геометрией Telegram; сохранены состояния, нажатия и доступность.
- Четыре палитры: классическая, дневная, ночная и тёмная. Работают выбор акцента, расписание ночной темы и выбор фона из галереи.
- Оригинальный рисунок обоев Telegram и градиент из его `image.cpp`. Форма текстовых сообщений перенесена из `MessageDrawable.java`; размер текста и углы пузырьков применяются к переписке.
- Оригинальные значки в боковом меню, заголовке чата и поле ввода. Профиль, устройства, уведомления, приватность и другие страницы используют общие компоненты настроек.
- После обновления объёмное оформление Komet заменяется новым. Аккаунт, история, выбранные фотографии и размер текста сохраняются.
- Сохранены исправления ввода номера, повторной отправки кода и загрузки истории из dev.3.

Для телефона скачивайте **arm64-v8a**. Версия x86_64 предназначена для эмулятора. Обновление устанавливается поверх предыдущей сборки Komet preview с тем же application ID.

Это Pre-release. Интерфейс реализован во Flutter поверх MAX-части Komet: это не сборка Java-интерфейса Telegram. Полное совпадение каждого экрана с Telegram ещё не подтверждено. Вход/CAPTCHA, медиа и звонки на реальном аккаунте, QR-привязка и наблюдение 72 часа остаются непроверенными. Собственная FCM-конфигурация MaxGram отсутствует; фоновые FCM-уведомления не настроены.

В релизе приложены исходники GPL, контрольные суммы, данные сборки и проверка запуска в Android. Снимки настроек, оформления и элементов управления содержат только синтетические данные; они доступны в `telegram-ui-screenshots.zip`.
