TG-MAX Ultimate 0.2.0-alpha.2 — экспериментальная сборка из исходников NagramXF с начальным MAX backend.

APK: ARM64 (`arm64-v8a`), Android 8.1 и новее. Подпись Android debug; это предварительная сборка для проверки. Исходный код этой сборки и SHA-256 приложены.

Экран «Устройства» получает список сеансов MAX. После подтверждения можно завершить все остальные сеансы. Названия основных разделов переведены для всех восьми вариантов языка.

Подключены бинарный WebSocket transport MAX по Komet, начальная маршрутизация входа по телефону/коду/паролю, диалоги/история и текстовые операции. Исходный интерфейс — NagramXF. QR-вход, Telegram API credentials, inherited updater, Telegram push registration и Firebase initialization отключены.

Проверки перед публикацией: JVM-тесты MAX backend, подготовка pinned source, полная компиляция APK и проверка подписи. Реальный вход в аккаунт и работа на физическом устройстве не подтверждены. Установка/запуск, если дополнительно проверены, отмечаются отдельно в результатах CI.

Пока не реализованы: исходящий звонок для подтверждения входа, восстановление через email, медиа/uploads, стикеры, истории, аудио/видеозвонки, фоновый MAX push, полная замена серверных настроек и gap recovery. Часть исходных меню Nagram возвращает `MAX_UNSUPPORTED_*`. Полный перенос 45 экранов из ТЗ ещё не завершён. Выбор языка ограничен ru/en/es/uz/pt/pt-BR/fr/be; полные upstream UI-переводы ещё не покрыты.

Этот APK не является прежним Compose auth-harness и не использует его демонстрационный код.
