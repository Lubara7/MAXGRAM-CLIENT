MAXGRAM CLIENT 0.3.0-dev.3

Android 8.1+ · ARM64 · прототип на NextAlone/Nagram 13.1.1.

Исправлен найденный в проверке установленного APK сбой первого запуска. Проверка чужого сертификата Nagram останавливала JNI_OnLoad, поэтому не регистрировались буферы локальной базы и приложение завершалось до входа. Подготовка форка убирает привязку к сертификату издателя Nagram; проверка подписи APK и совместимости с прежним ключом MaxGram сохраняется. Перед запуском очередей базы проверяется загрузка движка и запись/чтение нативного буфера.

Добавлено отладочное меню по семи нажатиям на версию: запись метаданных последних 512 пакетов MAX, просмотр, очистка и сохранение через системный выбор файла. Запись изначально выключена, разделена по аккаунтам и исключает содержимое пакетов и заголовки. Старые отладочные меню Telegram/Nagram отключены.

Исправлен переход из шапки чата: удержание больше не запускает поиск вместо профиля. Статусы MAX берутся из серверных полей presence/seen: скрытые «недавно» и «давно» не раскрывают точное время, для заблокированных показывается «был(а) давно». Подключены обновления статуса и запрос при открытии профиля; устаревший online ограничен сроком хранения 300 секунд. Неудачная загрузка списка чатов допускает повторную попытку.

Обновлён профиль нового входа до WEB 26.11.8 по актуальным исходникам официальной веб-версии MAX. Сохранённые профили действующих сеансов не меняются.

В ветке 0.3 реализованы раздельные профили WEB/mobile, JSON v11 для новых WEB-сеансов, импорт собственного WEB-сеанса с исходным INIT, обязательное согласие до подключения, экраны настроек сессии и шесть полей приватности MAX, серверный срок неактивности 1/3/6 месяцев, исправления пагинации истории и необязательное локальное хранение полученных удалённых сообщений. Имена из телефонной книги сопоставляются локально, ID профиля отображается как ID MAX. Вход содержит RU/EN, 44 страны, помощь и документы MAX; QR перенесён из входа, подтверждение устройства ещё не подключено.

Это изменения реализации, а не подтверждение всех сценариев на реальном аккаунте. Часть медиа, звонки, подтверждение QR, анимации и окончательная очистка меню ещё требуют доработки. Результаты проверки конкретного APK находятся в GitHub Actions. Нет подтверждённого 72-часового наблюдения аккаунта и нет гарантии отсутствия блокировок. Публикация GitHub Release заблокирована до выполнения критериев v2.
