# Интеграция с MAX

Проверено 8 ноября 2026 года по публичным страницам MAX:

- [Open Client API для альтернативных клиентов](https://dev.max.ru/docs/open-api/).
- [Программа и описание подключения](https://legal.max.ru/openclient-docs).
- [Публичная страница программы](https://go.max.ru/openclient).

Для реальной интеграции нужны доступ к программе, выданный приложению App-ID и полная техническая документация. Наличие App-ID не означает доступ ко всем функциям. Публичная ссылка на технический ZIP на момент проверки возвращала пустой архив; схемы авторизации из неё не получены.

Поэтому в каркасе нет придуманных URL, HTTP-контрактов и готового SDK MAX. `OpenClientAuthGateway` — явная заглушка, которая всегда возвращает `INTEGRATION_UNAVAILABLE`. Настройка `-Pmax.appId=...` сама по себе её поведение не меняет.

## Подключение адаптера

1. Получить документацию и параметры, относящиеся к TG-MAX Ultimate.
2. Уточнить транспорт, создание/повтор challenge, длину и доставку кода, дополнительные проверки, проверку и отзыв сессии, ошибки и ограничения.
3. Реализовать методы `OpenClientAuthGateway` с прямым соединением устройства и MAX. Отмену coroutine сохранять, сетевые сбои переводить в доменные ошибки.
4. Уточнить формат и правила хранения credential; адаптировать `Session` и хранилище, если этого требует SDK.
5. Проверить восстановление, выход, истечение, неверный код, лимиты и доступность нужных функций на разрешённых тестовых аккаунтах.
6. Сверить экраны с обязательными требованиями интерфейса из полученной документации, сохранив согласованный визуальный ориентир Telegram в доступных пределах.

Секретные сертификаты, ключи и session credentials не публикуются и не передаются в Gradle properties репозитория. App-ID — идентификатор приложения; локально его можно указать в пользовательском `~/.gradle/gradle.properties` как `max.appId=...`.

Bot API относится к чат-ботам и не используется для входа в личный аккаунт. Backend-посредник TG-MAX не создаётся: сетевой адаптер находится внутри Android-приложения. Отправки заявок и обращений от имени владельца этот каркас не выполняет.
