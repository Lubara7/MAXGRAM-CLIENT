# Архитектура

Целевая платформа — Android, API 26+. Kotlin, Compose и одна AppCompatActivity. AppCompatActivity нужна для совместимой смены языка на Android 12 и более ранних версиях. UI ориентируется на привычные паттерны Telegram/Nagram X; чужой исходный код не переносится.

## Границы

`AuthRoute` отображает `AuthUiState` и передаёт действия в `AuthViewModel`. ViewModel обращается к интерфейсу `AuthRepository` из независимого JVM-модуля `core/domain`. Реализация `MaxAuthRepository` использует `MaxAuthGateway` и `SessionStore`.

`app/AppModule.kt` — явная точка создания зависимостей. Для начального каркаса контейнер DI не требуется. UI и домен не знают о транспорте MAX, адресах серверов и формате SDK.

Сетевой адаптер выполняется на устройстве. Сервер TG-MAX, reverse proxy, хранение пользовательских данных на стороне разработчика и телеметрия не предусмотрены.

## Варианты сборки

`app` и `core/data` используют измерение `backend` с вариантами `demo` и `production`. Gradle выбирает только соответствующие исходники. Идентификатор demo-приложения имеет суффикс `.demo`; хранилища и ключи разных приложений изолированы.

`DemoMaxAuthGateway` отсутствует в production classpath. Production-адаптер возвращает `INTEGRATION_UNAVAILABLE`, пока реальный клиент не реализован. Автоматического перехода с production на demo нет.

## Состояние и жизненный цикл

ViewModel переживает изменение конфигурации. Телефон, код и challenge хранятся только в памяти; после уничтожения процесса неподтверждённый вход начинается заново. Успешная сессия восстанавливается через репозиторий и проверяется шлюзом. Секретные данные не включаются в сохранённое состояние Activity.

Состояние обновляется через StateFlow, Compose подписывается с учётом жизненного цикла. Повторные действия блокируются до завершения текущей операции. Отмена coroutine не преобразуется в пользовательскую ошибку.

## Дальнейшее развитие

Чаты, локальный кэш, загрузки, Media3, уведомления и фоновые соединения добавляются после подтверждения API и требований. Room, Retrofit и push SDK пока не подключены: они не нужны для текущего каркаса и не определяют транспорт Open Client API заранее.
