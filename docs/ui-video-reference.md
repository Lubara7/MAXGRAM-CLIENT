# MAXGRAM CLIENT — разбор Telegram / Nagram XF

Источник: `15167.mp4`, 720 × 1586, 4:46.401. В исходнике 35 890 кадров с переменной частотой. Это запись Nagram XF, а не MAX. Файл `15166.mp4` не был доступен; сопоставление с MAX ещё не выполнено.

Изображения и исходное видео находятся в отдельном пользовательском архиве; они не включены в этот публичный репозиторий.

Основа проекта обновлена 14 ноября 2026 года: используется официальный DrKLO/Telegram. Это видео Nagram XF остаётся визуальным референсом; целиком приложение Nagram и его дополнительные разделы не переносятся. Прежний запрет QR-входа отменён по новому требованию: разрешён собственный QR-сценарий MAX.

## Что включено в отдельный архив

- `index.html` — локальный навигатор по экранам и кадрам. По умолчанию показывает 573 опорных изображения с интервалом 0,5 с. Стрелки клавиатуры переключают изображения.
- Для просмотра каждого исходного кадра нажмите «Открыть исходное видео» и выберите ваш `15167.mp4`. Навигатор использует 35 890 исходных временных меток; видео не отправляется в сеть. Оригинал не продублирован в архиве.
- `frames/` — 573 изображения JPEG в разрешении 720 × 1586. Это выборка для карты меню, а не экспорт всех 35 890 кадров в изображения.
- `frame_index.csv` — полный индекс исходных кадров; `metadata.json` — параметры и контрольная сумма.
- `overview_*.jpg` — обзорные листы с приблизительными временными отметками.

## Наблюдаемая структура

Тёмная тема с красно-бордовым акцентом; скруглённые поля и панели; четыре нижние вкладки «Чаты», «Контакты», «Настройки», «Профиль». В записи видны список чатов, вход и страны, главные настройки, разделы Nagram, темы и цвета, стикеры/эмодзи, реакции, конфиденциальность, уведомления, данные и память, энергосбережение, устройства, языки, QR-панель профиля, профили, диалог, боковое меню и поиск.

## Решения для MAXGRAM CLIENT

1. Сохранять нативные компоненты Nagram: заголовки, поля с контуром, числовую клавиатуру, строки настроек, нижнюю навигацию, панели и пузыри сообщений. Цветовую схему считать настройкой темы.
2. Форму входа связать с MAX. Список стран оставить из 44 ранее согласованных стран, а список языков — из семи согласованных вариантов, даже если в Telegram-видео их больше. Вместо меню Telegram на входе использовать помощь и выбор языка.
3. Локальные параметры оформления, размера текста, жестов и воспроизведения анимаций отделять от серверных возможностей: им не требуется имитация Telegram API.
4. Аккаунт, сеансы, уведомления, реакции, стикеры и настройки приватности связывать с подтверждёнными командами MAX. Наличие элемента в Nagram не доказывает поддержку соответствующей команды в MAX.
5. Telegram QR-вход, Telegram Proxy, Premium/Stars и другие серверные функции Telegram не переносить как рабочие функции MAX. QR-панель профиля — отдельный сценарий: её можно оценивать только после проверки ссылок/приглашений MAX, не смешивая с QR-входом.
6. Облачную синхронизацию Nagram и операции Telegram в отладочном меню не включать без отдельной реализации для MAX. Локальную блокировку приложения отличать от пароля аккаунта MAX.
7. Серые кружки касаний, системную строку состояния, жестовую полосу и содержимое реальных аккаунтов не считать элементами дизайна клиента. Имена, телефоны и сообщения из записи не использовать как данные приложения.

## Границы этого разбора

Временные отметки служат ориентирами, а не точной разметкой начала каждой анимации. Для анимаций используйте исходный режим навигатора и соседние кадры. Размеры в записи — пиксели масштабированного видео; переводить их напрямую в Android dp нельзя без плотности исходного экрана.

В записи нет полного прохода по всем возможным экранам Telegram. Сравнение MAX ↔ Telegram, окончательная таблица возможностей API и точные требования ко всем переходам будут дополнены после получения доступного видео MAX. Этот файл не утверждает, что все перечисленные функции уже реализованы в APK.
