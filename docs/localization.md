# Локализация

Семь языковых групп, восемь вариантов. Другие языки не добавляются без отдельного запроса.

| Код | Язык | Каталог ресурсов |
|---|---|---|
| `en` | English, резервный | `values` |
| `ru` | Русский | `values-ru` |
| `es` | Español | `values-es` |
| `uz` | O‘zbekcha, латиница | `values-uz` |
| `pt` | Português, европейский вариант; обслуживает `pt-PT` | `values-pt` |
| `pt-BR` | Português, Brasil | `values-pt-rBR` |
| `fr` | Français | `values-fr` |
| `be` | Беларуская | `values-be` |

Переводы находятся в `core/localization/src/main/res`. Основной набор содержит английский текст, поэтому неподдерживаемая системная локаль получает английский интерфейс. `pt-PT` использует европейский португальский, `pt-BR` — отдельный набор.

`LanguageController` использует AppCompatDelegate и LocaleListCompat. Пустой тег означает «Как в системе». На Android 13+ настройка согласована с системным выбором языка приложения, на более ранних версиях сохранением управляет AppCompat (`autoStoreLocales`). Отдельного хранилища с дублирующей настройкой нет.

`app/res/xml/locales_config.xml` содержит явный список языков. `resourceConfigurations` в сборке приложения исключает остальные переводы зависимостей. Не следует одновременно включать автоматическую генерацию LocaleConfig.

Строки UI и ошибок берутся через Android resources. Названия языков в списке намеренно показаны на соответствующих языках. Названия стран создаются Android Locale на эффективном поддерживаемом языке интерфейса. Форматированные значения используют позиционные параметры; таймер использует plurals.

`LocaleCoverageTest` проверяет ключи, типы ресурсов, параметры подстановки, наличие `other` у plurals и точный список LocaleConfig. Перед публичным релизом переводы следует вычитать носителям языка; тесты проверяют техническую полноту, а не лингвистическое качество.
